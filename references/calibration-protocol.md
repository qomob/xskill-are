# 校准协议

> 本文件定义 xskill-are 评分系统的校准规范。当前所有参数（权重、惩罚除数、HRR 阈值、token 中位数）均为直觉设计，未经经验校准。本协议定义如何获取 ground truth 并校准。

---

## 问题定义

```
评分有效性 = f(权重准确性, 惩罚函数校准, 断言区分度, 测试覆盖度)

当前状态：4 个参数均未经经验验证 → 分数与真实质量的相关性未知
```

---

## Golden Dataset 构建

### 规模

| 阶段 | 样本量 | 目的 |
|------|--------|------|
| 冷启动 | 20 个 Skill | 初步校准，发现系统性偏差 |
| 标准 | 50 个 Skill | 统计显著的校准，可调整权重 |
| 持续 | 每季度 +20 | 追踪评分漂移 |

### 样本选择

- 覆盖至少 5 个领域（技术/营销/分析/内容/教育）
- 包含已知高质量（人工验证 S/A 级）和已知低质量（人工验证 C 级）的 Skill
- 高低比约 3:2（偏高质量，但保证低质量样本够用）

### 标签方法

每个 Skill 由 **2 名人类专家独立评分**（使用相同 6 维度 rubric），取平均值作为 ground truth：

- 两人评分差异 > 15 分 → 第三人仲裁
- ground truth = 仲裁分或平均分

## 校准项目

### 1. 权重校准

当前权重（25/20/20/15/10/10）为直觉设计。校准方法：

```
对 Golden Dataset 中的每个 Skill i：
  predicted_i = Σ(dimension_score_i × weight_j)
  actual_i = human_ground_truth_i

使用线性回归拟合最优权重：
  minimize Σ(predicted_i - actual_i)²

约束：所有权重 ≥ 5%（防止某维度被消零），Σ(weights) = 100%
```

### 2. 惩罚函数校准

当前惩罚除数 /12 未经验证。校准方法：

```
测试除数范围 [8, 10, 12, 15, 20]：
对每个除数 d：
  计算所有 Golden Dataset Skill 的 finalOverall_d
  计算 correlation(finalOverall_d, human_ground_truth)

选择 correlation 最高的 d 值。
若差异 < 0.02，保留当前 /12（避免过拟合）。
```

### 3. HRR 阈值校准

当前 HRR 人工修改率（<15%/15-30%/30-50%）为假设。校准方法：

```
收集 Golden Dataset 中每个 Skill 的「实际人工修改率」：
  - 部署后跟踪用户修改比例
  - 或由专家评估"需要修改多少才能用"

拟合 HRR Tier 边界：
  S: 实际修改率 ≤ P15（第15百分位）
  A: P15 ~ P30
  B: P30 ~ P50
  C: > P50
```

### 4. Token 中位数校准

当前 `MEDIAN = 12000` 来源未知。校准方法：

```
收集 100+ 次评测的实际 token 消耗
计算真实中位数
若偏差 > 20%，更新 MEDIAN 值
```

## 当前状态

### 冷启动校准：已完成（2026-07-11）

**Golden Dataset 规模：** 25 Skills（工作空间内全部非 xskill-are 的 Skill，含 6 个工具类 Skill）

**覆盖领域：** 教育/房产、创业/商业、营销/广告、设计/视觉、项目审计、内容创作、舆情分析、风险管理、投资/金融、影视/视频、短视频/电商、工程方法论、创意/命名、三农、本地生活、招聘/系统配置、Skill 构建、SEO/GEO、法律诉讼、模型路由、任务拆解 — 共 21 个领域。

**标注方法：** 双评估者共识（J1 原始视角 + J2 怀疑者透镜），基于 SKILL.md 静态分析 + 架构审查。consensus = (J1+J2)/2。J2 使用更严苛标准（对"功能多但无验证"、"安全只是声明"、"references 空或断裂"扣分）。非真正 2-expert 人类协议。

### 回归校准结果

| 校准项 | 旧值 | 新值 | 改善 |
|--------|------|------|------|
| **权重** | [25,20,20,15,10,10] | **[28,22,18,14,10,8]** | Pearson r 0.97→0.99 |
| **惩罚函数** | 二次 `100-(100-x)²/12` | **线性拉伸 `x×1.5-35`** | rawScore 60-75 区间从趋零修正为合理区间 |
| **HRR S 阈值** | ≥85 | **≥85**（不变） | 6/6 S 级 Skill 正确捕获 |
| **HRR A 阈值** | ≥70 | **≥68** | 覆盖得分 68-69 的 A 级 Skill |
| **HRR B 阈值** | ≥50 | **≥48** | 覆盖得分 48-49 的 B 级 Skill |
| **Token MEDIAN** | 12,000 | **22,000** | 旧值偏低 86.6%，D6 系统性给所有 Skill 打低分 |

### 评分者间一致性

| 指标 | 值 | 说明 |
|------|-----|------|
| J1 vs J2 Δ 均值 | 4.4 分 | 可接受范围（<10 分） |
| J1 vs J2 Δ 中位数 | 4.0 分 | |
| J1 vs J2 Δ 最大值 | 6 分 | xgeo（D3/D4/D6 分歧最大） |
| Tier 一致率 (J1=J2) | 18/25（72%） | 分歧全在 S/A 边界 |

### HRR 分级准确率

**21/25（84%）** consensus tier 与 ground_truth tier 一致。4 个偏差：
- 3 个 S/A 边界（verdict/skill-compiler/xgeo 预测 S 实际 A）— 线性拉伸在高分端略有通胀
- 1 个 B/C 边界（local-life-operations 预测 B 实际 C）

无跨级错误（S↔B, A↔C 等）。

### Pearson 相关性

| 公式 | Pearson r |
|------|-----------|
| 旧（权重[25,20,20,15,10,10] + 二次/12） | 0.9661 |
| 新（权重[28,22,18,14,10,8] + 线性拉伸） | **0.9896** |

25 Skills 权重重新拟合（梯度上升）后最优 r = 0.9975，但差异仅 0.008（<0.02），保留当前权重避免过拟合。

### Token 中位数校准

基于 25 Skills 的 SKILL.md 实际文件大小（中英混合文本 ÷2.5 bytes/token）+ Pipeline 结构估算：

| 指标 | 值 |
|------|-----|
| SKILL.md tokens 中位数 | 6,456 |
| D1+D3+D4 平均/dim 中位数 | **22,393 tokens** |
| 全评测总 token 中位数 | 75,043 tokens |
| 旧 MEDIAN | 12,000 |
| 偏差 | **86.6%**（严重偏低） |
| 新 MEDIAN | **22,000** |

旧 MEDIAN=12000 导致 D6 性价比维度系统性给所有 Skill 打 40 分（最差档），因为实际平均 token 消耗几乎都 >18,000。

### 局限性声明

当前 Golden Dataset 的 ground_truth 由 AI 双评估者标注（J1 原始视角 + J2 怀疑者透镜），非人类专家共识。Token 中位数为静态结构估算，非真实运行时数据。分数应被视为**冷启动校准后的参考信号**，置信度高于纯直觉设计，但低于 2-expert 人类协议 + 100+ 真实评测标准。建议在累计 50+ 人类标注 + 100+ 真实评测后执行标准规模重新校准。
